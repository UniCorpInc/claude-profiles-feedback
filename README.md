# Claude Profiles: feedback

This is where to report bugs, ask for features and share feedback about **[Claude Profiles](https://marketplace.visualstudio.com/items?itemName=UniCorp.claude-profiles)**, the VS Code extension for using a different Claude Code account in each window, sharing a folder's history between accounts, and continuing when one hits its usage limit.

## Report a problem

The quickest way is **Report a Problem…** in the Claude Profiles panel's **⋯** menu (or the Command Palette). It opens a new issue with your extension, VS Code and OS versions filled in.

Or [open an issue](https://github.com/UniCorpInc/claude-profiles-feedback/issues/new) and include:

- What you did, what you expected, and what happened instead
- Your Claude Profiles and VS Code versions, and your OS
- Whether it's a remote window (SSH, WSL, container)

**Please don't paste** sign-in tokens, account emails you'd rather keep private, or Claude conversation contents. Issues here are public.

## Rate it

If Claude Profiles is useful to you, a [rating on the Marketplace](https://marketplace.visualstudio.com/items?itemName=UniCorp.claude-profiles&ssr=false#review-details) helps other developers find it.
